# 物业公区巡查整改系统

面向物业公区（**电梯厅 / 楼道 / 垃圾房**）的“巡查上报 → 扫码整改 → 经理审核 → 扣分徽章”闭环管理系统。

## 角色与入口

| 角色 | 进入方式 | 能做什么 |
|---|---|---|
| 经理 | 账号登录 `/` | 审核配对整改图、查看扣分徽章、员工/二维码管理、重新生成 token、停用链接、查日志 |
| 巡查员 | 账号登录 `/` | 拍照上报问题、指派保洁/维修、设扣分与时限、跟踪自己的巡查单 |
| 保洁 / 维修 | **专属二维码链接** `/w/<token>`（无需登录） | 只看本人任务、查看问题照、上传整改照；驳回后可重新提交 |

## 快速开始

```bash
npm install
npm start                 # 默认 http://localhost:3000
PORT=8080 npm start       # 自定义端口
```

首次启动自动创建 SQLite 库（`data/patrol.db`）、演示数据与示例图片（SVG）。
删除 `data/` 与 `uploads/` 可恢复初始状态。

## 核心流程

1. **巡查上报**：巡查员选择点位（电梯厅/楼道/垃圾房）、位置、整改人、扣分值（1–20）、整改时限，上传 1–6 张问题照。
2. **扫码整改**：系统给每个保洁/维修人生成专属 token 链接与二维码；员工扫码进入 H5，看问题照并上传整改照（可拍照）。
3. **经理审核**：经理在待审队列查看**整改前/后配对对比图（拖动滑块）**，一键通过或驳回；驳回后员工重新提交。
4. **扣分徽章**：按已通过问题单累计扣分自动分级：
   💚 满分卫士(0) · 🔵 轻微提醒(1–5) · 🟡 黄牌警示(6–10) · 🔴 红牌警告(11–20) · ⬛ 重点督办(>20)
   附加徽章：⚡ 准时之星、⏰ 超时较多、🛗/🚪/🗑️ 点位高频、🌟 一次通过率高。

## 安全与管理功能

- **重新生成 token**：经理一键轮换，旧链接立即失效（SHA-256 比对，库内 AES-256-GCM 密文保存）。
- **停用员工链接 / 停用账号**：扫码端显示停用提示，无法再提交整改照。
- **全量操作日志**：登录、创建问题单、提交整改、审核通过/驳回、token 轮换、停用链接/账号、重置密码、服务启动均记录；支持筛选、搜索与 CSV 导出。
- 密码使用 scrypt 加盐哈希；登录态为 7 天 JWT；照片接口分别做登录/归属鉴权；上传限图片类型、单张 10MB、单次 6 张。

## 技术栈

Node.js 20 + Express + better-sqlite3 + JWT + multer + qrcode，原生 HTML/CSS/JS（无前端构建步骤）。
